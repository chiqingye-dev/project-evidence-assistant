# 图文学习流程

本地0.4.2候选把 `tech-doc-to-feishu` 的分析方法接入正常的章结构与小节正文生成。内容继续保存在原学习记录中，由原网页阅读区展示；没有飞书账号、导出或发布步骤。

## 学习内容怎么组织

| 学习角度 | 在现有流程中的作用 |
| --- | --- |
| 需求分析 | 从具体场景说明为什么需要当前能力 |
| 问题推演 | 解释不用该机制会出现的问题 |
| 方案与取舍 | 结合源码解释实现，比较有意义的替代方案和代价 |
| 完整链路 | 用流程、时序、状态或关系图解释正常与异常路径 |
| 测试验证 | 区分已有验证证据与建议执行的测试 |
| 总结与提升 | 给出结论、缺口、面试问答及可选的定位/解释/预测练习 |

六个角度作为讲解组织规范，保留查询、提交、消息消费、判题四主题及原章/节选择。根据当前小节采用相关角度，不在每次点击时生成整本长文，也不强制每题三个方案或固定图表数量。

`prompts/learning-guide.txt` 由适配器加载到新章结构/小节任务，共同摘要记录指导文本版本。现有字段、1200字符/块、12块等输出限制和工具/来源/费用限制继续适用；目录任务和正在试验的追问运输没有被这次规范替换。

## 网页怎么阅读

正文支持短段落、强调、代码、列表及表格。独立的 Mermaid 围栏可显示流程图、时序图、状态图和ER图；窄屏可以横向滚动图表。无法渲染、包含配置/交互/外部内容或不支持的图保留原文显示。

标题以“面试问答：”“面试追问：”“学习检查：”或“自测：”开头的块显示为可展开的问题，内含模型给出的参考回答或检查要点。展开答案不产生模型费用、不改变阅读标记或本人掌握状态。点击引用继续打开该块对应的原已保存证据。

正文仍是原block的text，不另存另一份图文文档，不改变数据库Schema或旧内容。新任务采用新规范；已保存内容免费读取，若原文没有图表或问答，不会自动补写或付费重生成。

## 可信边界

图形、表格和参考答案同样需要源码支持；“有图”“有引用”都不证明解释正确。教学类比、替代方案、建议测试与历史验证要明确区分，设计动机不能冒充原作者记录，不能自动宣称用户独立实现或已经掌握。

Mermaid 12.3.0固定在本机，使用隔离沙箱及严格模式；仅加载同源的固定版本库，图自身不能联网或访问应用状态。大文件提供确定性gzip副本以避免静态加载等待。没有外部图表服务或浏览器图片URL请求，第三方许可证见THIRD-PARTY.md。

本轮完成工程与合成浏览器展示验证，未调用真实模型。新的图文教学质量仍需真实生成后逐条核对；不据此提升F02/V1的验收状态。
